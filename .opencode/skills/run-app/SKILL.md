---
name: Run App
description: Install, run, lint, or build the historic-figure-chatbot Vite app
---

Run these from the assignment directory. Node.js 20.19+ or 22.12+ is required.

1. Install dependencies with `npm install` when `node_modules` is missing or `package-lock.json` changed.
2. Start the UI with `npm run dev`.
3. Check JSX with `npm run lint`.
4. Build with `npm run build`.
5. Do not commit `node_modules` or `dist`.
