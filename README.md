# Software Engineering chatbot

## Download the project
```bash
git clone https://github.com/RubenM0/historic-figure-chatbot.git
cd historic-figure-chatbot
npm install
npm run dev
```

## Run the backend (make sure node.js is intalled first)
```bash
cd historic-figure-chatbot/myserver
npm install
#If the above install doesn't work
npm.cmd install
```

```bash
cd historic-figure-chatbot/myserver
node index.js
```
